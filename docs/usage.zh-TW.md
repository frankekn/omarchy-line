# 使用面板

[English](usage.md)

這一頁是日常使用的說明：鍵盤操作、傳檔案、通知、隱藏聊天室，以及各項設定。安裝與
登入請看 [README](../README.zh-TW.md)。

## 打開聊天室與已讀

點 bar 上的圖示打開面板。聊天列表會把有未讀的排在前面。直接打字就能搜尋聊天室名稱
和訊息預覽。

daemon 只對你正在看的聊天室送出已讀。`Center of screen` 和 `App window` 位置會把
清單和聊天室並排顯示。按 Esc 回到清單後，聊天室還留在右欄，但裡面的新訊息不會被標成
已讀。要再看這個聊天室，點清單裡的那一列，或點進它的回覆框。點回覆框會為這段期間
進來的訊息送出一次已讀。

捲到最上面會載入更舊的訊息。打開聊天室時，第一則未讀訊息上方會有一條**未讀訊息**
分隔線。

## 通知

daemon 只在面板關著的時候發桌面通知。面板開著時，訊息本來就在畫面上了。你自己傳的
訊息和隱藏的聊天室都不會發通知。同一個聊天室兩秒內最多發一則，因為相簿或被拆成好幾段
的長訊息會一口氣進來一串。

一則通知包含這些部分：

- 標題是聊天室名稱。一對一聊天時就是對方的名字。
- 群組裡的內文是傳送者加上訊息，寫成 `名字: 訊息`。一對一聊天時，內文只有訊息本身。
- 圖示是聊天室的大頭貼。daemon 還沒下載到大頭貼的話，最多等三秒，之後就不帶圖示先發。

不論面板設成哪種語言，通知文字一律是繁體中文。沒有文字的訊息會顯示成 `[貼圖]`、
`[圖片]`、`[影片]`、`[語音]` 或 `[檔案]`。其他沒有文字的訊息，例如解不開的加密訊息，
會顯示成 `[新訊息]`。

點通知會打開面板並直接進到那個聊天室。daemon 呼叫 `notify-send` 時會帶
`--action=default=開啟`。Omarchy 的通知服務在你點通知時，會執行名稱為 `default`
的 action。沒有這個 action 的話，它會試著把送通知的程式視窗叫到前面，但面板根本沒有
視窗可以叫。你點下去之後，daemon 會把聊天室寫進 `state.json` 的 `wanted`（見
[protocol.zh-TW.md](protocol.zh-TW.md#wanted從通知點進來的聊天室)），再執行
`omarchy-shell io.github.frankekn.line open`。

通知的 action 只有在送出它的 `notify-send` 行程還在跑時才有作用。所以每個
`notify-send` 行程會留到你關掉那則通知為止，最多十分鐘。十分鐘一到，daemon 會結束
這個行程，之後再點那則通知就沒有反應。

`notify-send` 來自 `libnotify` 套件，Omarchy 預設就有裝。缺少它的話，daemon 會在
journal 寫一次 `[notify] notify-send not found; notifications disabled`，之後就不再
發通知，其他功能照常運作。daemon 不會把通知內容寫進 journal。

## 鍵盤操作

有些鍵要先離開輸入框才有作用，按 Esc 就能離開。在輸入框裡，`/`、`L` 和 `r` 就只是
一般的字元。

在聊天列表：

| 按鍵 | 動作 |
|---|---|
| 直接打字 | 搜尋聊天室名稱、傳送者和訊息預覽。 |
| ↑ ↓ | 選聊天室。 |
| Enter | 打開選到的聊天室。 |
| Esc | 清空搜尋。搜尋框是空的時候，離開輸入框。再按一次 Esc 關閉面板。 |
| `L` | 離開輸入框後：選到「登出」。再按 Enter 或空白鍵才會登出。 |
| `r` | 離開輸入框後：立刻同步，等同按「同步」。 |

在聊天室裡，焦點在回覆框時：

| 按鍵 | 動作 |
|---|---|
| Enter | 送出訊息。 |
| Shift+Enter | 換行。 |
| `/file <路徑>` | 傳檔案。 |
| Ctrl+V | 送出剪貼簿裡的圖片。剪貼簿裡是文字的話，就貼上文字。 |
| Esc | 一次退一層：先關貼圖選單，再關 @ 選單，再取消引言（草稿留著），最後離開回覆框。 |

在聊天室裡，離開回覆框之後：

| 按鍵 | 動作 |
|---|---|
| `/` | 回到列表，焦點移到搜尋框。 |
| Esc | 回到列表。 |
| `r` | 立刻同步。 |
| ↑ ↓、`j` `k` | 捲動訊息。 |

在群組裡打 `@` 會跳出 @ 選單。繼續打字可以用顯示名稱篩選成員，不分大小寫。按 ↑ 或
↓ 選人，按 Enter 或 Tab 插入名字。按 Esc 會關掉選單，已經打的字會留著。

按 😊 按鈕開關貼圖選單。點一張貼圖就會送出。按 Esc 或點選單外面就會關掉。滑鼠滾輪
可以左右捲動貼圖包那一列，放不下時兩端會出現 ‹ › 按鈕。⟳ 按鈕會重新下載貼圖清單。
離開回覆框之後，← →（或 `h` `l`）切換貼圖包，↑ ↓ 還是捲動訊息。在回覆框裡，← → 是
移動游標。

貼圖選單開著時，Esc 只會關掉選單，聊天室不會跟著退回列表。切換聊天室、離開聊天室或
登出也都會關掉選單，所以挑到的貼圖不會送到別的聊天室去。

要複製文字，在訊息上按住左鍵拖曳，再按 Ctrl+C。Ctrl+Shift+C 會複製整則訊息。按 Esc
會取消反白，焦點回到回覆框。

在看圖模式：

| 按鍵或操作 | 結果 |
|---|---|
| ← →（或 `h` `l`） | 上一張或下一張。 |
| 滑鼠滾輪 | 縮放。 |
| 拖曳 | 平移。 |
| 雙擊 | 在 1× 和 2× 之間切換。 |
| `o` | 用外部程式開這張圖。在兩種疊加式位置，面板會先關掉。 |
| Esc，或點背景 | 關掉看圖模式。 |

看圖模式開著時，只有上面這些鍵有作用，連 `r` 都不會有反應，要先關掉看圖模式再同步。
關掉之後，焦點會回到原本的地方：在聊天室是回覆框，在列表是搜尋框。

`r` 會直接同步，不像 `L` 要多一步確認。同步不會弄丟任何東西，多按一次也只是多更新
一輪。

## 滑鼠操作

- 點連結會用 `xdg-open` 在預設瀏覽器打開。只有 `http://` 和 `https://` 的連結會開，
  其他連結會顯示「這個連結打不開」。
- 在訊息上按右鍵會打開選單。最上面一列是六個表情，下面是「複製訊息」、「複製連結」、
  「開啟連結」、「回覆」和「收回」。「複製連結」和「開啟連結」只有在連結上按右鍵時
  才會出現。「回覆」只有面板認得出這則訊息時才有，「收回」只出現在你自己傳的訊息上。
  圖片、貼圖和檔案也有同樣的選單。
- 點訊息下方的表情，會加上同一個表情。點你自己的表情會收回它。
- 點回覆上方的引言，會跳到原本那則訊息。
- 點空白的地方會取消反白，焦點回到回覆框。

在 `Below the bar` 和 `Center of screen` 位置，面板打開連結或檔案之前會先關掉，免得
瀏覽器或檢視器被壓在面板下面。`App window` 位置的面板會留著。

複製用的是 `wl-clipboard` 套件裡的 `wl-copy`。文字從標準輸入交給 `wl-copy`，不會出現
在命令列上。Omarchy 沒有把 `wl-clipboard` 列為相依套件，但它的剪貼簿外掛和網路面板
都會用到，所以大部分系統都有。缺少它的話，複製時會顯示「複製失敗：系統裡找不到
wl-copy」。執行 `sudo pacman -S wl-clipboard` 安裝之後就能馬上使用。

## 傳檔案與圖片

- 按 `📎` 選檔案，或在回覆框輸入 `/file <路徑>`。選檔視窗需要 `zenity`，沒裝的話
  按 `📎` 會提示你安裝。
- 在回覆框按 `Ctrl+V` 可以直接送出剪貼簿裡的圖片，這需要 `wl-clipboard`。剪貼簿裡
  是文字的時候，`Ctrl+V` 照常貼上文字。
- 圖片（含 GIF）上限 20 MB，影片與其他檔案上限 1 GB。超過的檔案在上傳前就會被擋下。
- 圖片會以圖片送出，影片以影片送出。音訊一律以檔案送出。
- 有裝 `ffmpegthumbnailer` 或 `ffmpeg` 時，送出的影片才會有預覽圖。兩個都沒有的話
  影片照樣送得出去，只是沒有預覽圖。
- 多人聊天室（聊天室 id 以 `r` 開頭）不能收檔案。
- LINE 的聊天檔案只保留 7 天。過期的檔案會標上「（已過期）」，點了也打不開。被收回
  的訊息會顯示成一行「已收回訊息」。

影片和檔案用外部程式開啟。在兩種疊加式位置下，面板會先關掉，免得檢視器被壓在面板
下面。傳送與下載的運作方式見 [architecture.zh-TW.md](architecture.zh-TW.md#媒體流程)。

## 隱藏聊天室

在列表上對聊天室按右鍵，選「隱藏聊天」。這個聊天室會離開列表，有新訊息也不會跑
回來、不發通知，也不算進 bar 圖示上的未讀數。要再找到它，就在搜尋框打字，它會出現
在結果最後面並標著「已隱藏」，同一個選單裡有「取消隱藏」。

隱藏只是這台電腦上的偏好。LINE 沒有地方存這個設定，所以手機上不會跟著隱藏。daemon
把隱藏的聊天室記在 `~/.local/state/enil/hidden.json`。隱藏不是「退出聊天」，你在每台
裝置上都還在群組裡。

## 設定

面板把每個設定存在 Omarchy 的 `shell.json`，重開機之後設定還在。你可以用搜尋框旁邊
的按鈕調整，也可以用 `omarchy bar set`。

### 介面語言

`language` 可以是 `System`、`繁體中文` 或 `English`。`System` 跟著系統語系走：語系
以 `zh` 開頭就用繁體中文，其他一律用英文。在英文系統上想用繁體中文，就明確指定：

```bash
omarchy bar set io.github.frankekn.line language "繁體中文"
```

面板顯示 daemon 傳來的錯誤訊息和訊息佔位字時，也會照這個設定翻譯。daemon 本身一律
用繁體中文傳送。通知是 daemon 發的，所以一律是繁體中文（見[通知](#通知)）。

### 字級

`A−` 和 `A+` 按鈕每次把 `textScale` 調 10，範圍是 80 到 160（%），預設 100。

```bash
omarchy bar set io.github.frankekn.line textScale 130
```

### 捲動速度

`捲動 1×` 按鈕顯示滑鼠滾輪的速度（`scrollSpeed`，單位是 %）。每按一下換到下一段：
0.5×、0.75×、1×、1.5×、2×、3×，再回到 0.5×。聊天列表、訊息和貼圖選單都套用這個
速度。預設是 1×，一般滑鼠滾一格大約 60 像素。

```bash
omarchy bar set io.github.frankekn.line scrollSpeed 150
```

50 到 300 之間的任何數字都可以，不限上面那幾段。按鈕會顯示你設的值，再按一下就跳到
比它大的下一段。

Qt 的 `Flickable` 沒有「滾輪一格捲多遠」的設定，所以面板自己計算滾輪的距離。一般
滑鼠滾一格是 60 像素（跟著主題的間距縮放）乘上速度。觸控板則是它回報的實際距離乘上
速度，所以調快之後，觸控板不會一滑就是一整頁。貼圖選單裡左右捲動的那兩列（貼圖包
那一列和最近用過的貼圖）也套用同一個速度，只是一格是它們自己的距離，大約兩個貼圖包
或一張貼圖。拖曳、觸控、捲軸和 `j` `k` 鍵不受這個設定影響。

### 每次讀取的訊息數

`讀取 60` 按鈕顯示面板一次跟 daemon 要幾則訊息（`historyPage`）。打開聊天室的第一頁
和往上翻的每一頁都用這個數字。每按一下換到下一段：30、60、100、150，再回到 30。
預設是 60。

```bash
omarchy bar set io.github.frankekn.line historyPage 100
```

20 到 200 之間的任何數字都可以。按鈕會找比目前值大的下一段，所以手動設成 37 的話，
下一下會跳到 60。daemon 也最多只接受 200：它把 socket 收到的 `count` 限制在 1 到
200，`count` 不是數字時就用 30。

數字越大，打開聊天室時第一頁載入越慢，但往上翻時要跑的請求比較少。設成 30 的話，一頁
大概只夠填滿一個畫面，幾乎每往上翻一次都要等網路，所以預設是 60。

離頂端還有一個畫面高時，面板就會先去要下一頁更舊的訊息，所以捲到頂的時候，那一頁
通常已經接上了。面板一次只送一個請求。daemon 回傳空的一頁時，代表已經到最舊的訊息，
面板就不再要了。重新打開聊天室或同步之後會重新開始。

### 面板位置

`placement` 有三個值。搜尋框右邊的按鈕顯示目前是哪一個，每按一下換到下一個。下表
列出設定值和中文介面上的按鈕文字。

| 設定值 | 按鈕文字 | 版面 | 適合 |
|---|---|---|---|
| `Below the bar`（預設） | 貼齊 bar | 在 bar 圖示下方開成單欄，列表和聊天室互相切換。 | 快速看一下未讀訊息。 |
| `Center of screen` | 置中 | 開在螢幕正中央，左邊是列表，右邊是聊天室。 | 回幾則訊息。 |
| `App window` | 視窗 | 一般的 Hyprland 視窗，分成兩欄。 | 一直開著當聊天軟體用。 |

```bash
omarchy bar set io.github.frankekn.line placement "App window"
```

`Below the bar` 和 `Center of screen` 是 `WlrLayer.Overlay` 圖層，永遠蓋在所有視窗
上面，Hyprland 的視窗規則也管不到它們。`App window` 是一般視窗：它會照你的規則平鋪
或浮動，Alt+Tab 切得到，也能移到別的工作區。外部的看圖或影片程式會開在它上面，所以
面板不用先關掉。它的視窗 class 是 `org.quickshell`，title 是 `LINE`。Omarchy 自己的
開發者 gallery 也用同一個 class，所以規則裡也要比對 title。要讓它浮動的話：

```bash
# ~/.config/hypr/windows.conf（或你放 windowrule 的地方）
windowrule = float, class:^(org\.quickshell)$, title:^(LINE)$
windowrule = size 1040 720, class:^(org\.quickshell)$, title:^(LINE)$
```

視窗會記住自己的大小。你停止調整浮動視窗的大小 0.8 秒後，面板會把大小存進
`windowWidth` 和 `windowHeight`。平鋪視窗的大小由版面決定，所以面板不會記。也可以
直接指定大小：

```bash
omarchy bar set io.github.frankekn.line windowWidth 1280
omarchy bar set io.github.frankekn.line windowHeight 860
```

三種位置的按鍵操作都一樣，只有一個例外：Tab 會切換到 bar 上的下一個面板，而
`App window` 不是 bar 面板，所以在那裡按 Tab 不會有反應。

## 已知限制

- 這是非官方 client，使用它會讓你的帳號承擔風險。見[免責聲明](../README.zh-TW.md#免責聲明)。
- 面板介面只有繁體中文和英文。訊息內容不會翻譯。
- 多人聊天室（聊天室 id 以 `r` 開頭）不能收檔案。linejs 的 `uploadMediaByE2EE` 只接受
  `u` 和 `c` 開頭的聊天室。
- E2EE 影片顯示 📎，沒有預覽圖。它的預覽圖也是加密的，要下載整支影片才拿得到。
- 送出的影片只有在裝了 `ffmpegthumbnailer` 或 `ffmpeg` 時才有預覽圖（見
  [傳檔案與圖片](#傳檔案與圖片)）。面板不強制要求影片解碼器。
- 送出的影片不帶解析度（`WIDTH` 和 `HEIGHT`）。要知道解析度就得解出一格畫面，而預覽圖
  那一步可能根本不存在。
- AVI 檔讀不出長度。`RIFF` 格式沒有把長度放在檔頭的固定位置，LINE 也不會自己算。
